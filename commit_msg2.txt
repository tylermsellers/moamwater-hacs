auth: fix crash when methodType option value is a bare string (v0.2.2)

_extract_authenticator_option() assumed every methodType option's "value"
was always a nested dict with its own "form", but Okta's IDX response can
return a bare string there instead (e.g. "sms") -- confirmed live:
"AttributeError: 'str' object has no attribute 'get'" at
_extract_authenticator_option, right after successfully getting through
stateToken extraction, introspect, identify, and the password answer.

Fix: guard with isinstance(option_value, dict) before treating it as
nested, otherwise use the string directly as methodType.
